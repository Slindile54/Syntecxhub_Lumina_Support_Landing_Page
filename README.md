# Syntecxhub_Lumina_Support_Landing_Page
Lumina Support Landing Page Description  Designed a modern, responsive IT support landing page for Lumina Support. The project focuses on clean UI/UX, intuitive navigation, reusable components, responsive layouts, and interactive Figma prototypes to create a professional and user-friendly support experience.

## Syntecxhub Internship Project

A modern responsive landing page design for Lumina Support, a fictional IT support platform.

## Project Features

- Responsive landing page
- Hero section
- Feature section
- Smart Ticket Management
- AI-Powered Assistance
- Support Analytics
- Get Started section
- Contact section
- Book a Demo flow
- Interactive Figma prototype
- Responsive desktop, tablet and mobile designs

## Tools

- Figma
- Auto Layout
- Components
- Variants
- Figma Prototyping

## Design

The interface uses a clean white and soft lavender colour palette with dark purple and teal accents.
